# Contributing

This project has one maintainer, [@paulbennet](https://github.com/paulbennet). It does not take pull requests.

To report a bug or ask for a feature, [open an issue](https://github.com/paulbennet/agent-response-config/issues/new). Include:

- the agent and its version (Claude Code, Codex or Copilot),
- the operating system,
- the output of `node <skill-dir>/scripts/config.mjs --show`,
- what you expected and what happened.
